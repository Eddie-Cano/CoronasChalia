# Coronas Chalía

Sitio de presentación y pedidos por WhatsApp para coronas artesanales de Actopan, Veracruz.

## Contenido

- Las 11 fotos reales y el logo aprobado.
- Galería por colores y vista ampliada.
- Selección de modelo o idea personalizada.
- Mensaje de consulta al número +52 229 219 8913.
- Nombre, colores, tamaño, cantidad, fecha y notas.

El cliente envía el mensaje en WhatsApp. El sitio no confirma disponibilidad ni precios ni registra datos en un servidor.

## Vercel

Importar el repositorio CoronasChalia. Framework: Other. Directorio raíz: raíz del repositorio. Directorio de salida: dist. Sin comandos de instalación ni compilación. vercel.json incluye esta configuración.

La dirección deseada es coronaschalia.vercel.app; su asignación depende de disponibilidad.

## Vista local

Ejecutar `python3 -m http.server 8000 --directory dist` y abrir http://localhost:8000.

## Archivos

- dist/index.html: contenido y formulario.
- dist/styles.css: diseño adaptable y paleta.
- dist/app.js: galería y preparación de mensajes.
- dist/assets/: logo y fotografías.

Los enlaces a las fotos en WhatsApp se generan usando el dominio donde se abre la página.
